# 전기산업기사 공식 시험 규칙 확인

2026-10-21에 Q-Net의 전기산업기사(종목 코드 `2140`) 종목별 상세정보를 직접 읽었다.

- 종목 페이지: https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=2140
- 시험정보 탭 원문: https://www.q-net.or.kr/crf005.do?id=crf00503s02&jmCd=2140&jmInfoDivCcd=B0
- 시행기관: 한국산업인력공단.

시험정보의 **취득방법**에서 확인한 내용:

> 필기 1. 전기자기학 2. 전력공학 3. 전기기기 4. 회로이론 5. 전기설비기술기준
>
> 객관식 4지 택일형, 과목당 20문항(과목당 30분)
>
> 100점을 만점으로 하여 과목당 40점 이상, 전과목 평균 60점이상

따라서 총 100문항·150분이며, 각 과목은 정답 수/20×100으로 계산한다. 각 문항 동일 배점으로 과목당 한 정답은 5점, 전체 평균에서는 1점이다. 과목별 8개 이상 정답과 전체 60개 이상 정답을 모두 요구한다. 평균이 높아도 한 과목 7개 정답이면 불합격이다. 표시값 반올림을 합격 판정에 사용하지 않는다. 미응답은 정답으로 인정하지 않으며 오답노트에 포함한다. 앱은 과목별 별도 타이머가 아닌 합산 150분을 사용하며 실제 CBT 운영 UI를 완전히 복제했다고 주장하지 않는다.

**출제경향**에는 전기설비기술기준·한국전기설비규정 등을 시험 시행 전 최근 고시된 기준 및 규정으로 준비해야 한다고 적혀 있다. 현재 은행은 그 법규 수치를 담지 않으며 최신 KEC 대비 완료가 아니다.

조사 시작 때 프록시 CONNECT 403이었으나 Q-Net 도메인을 설정 초안에 추가한 후 재시도하여 HTTP 200 본문을 확보했다. 탭은 AJAX로 로드되므로 메인 HTML만으로 규칙을 확인하지 않았다. 메인 페이지의 `goContents`가 지정한 `jmInfoDivCcd=B0`의 취득방법 내용을 읽었다.

시험정보 페이지에는 2024.1.1–2026.12.31 및 2027.1.1–2029.12.31 출제기준 링크가 있다. 이는 실제 확인한 링크 목록이며, 세부 출제기준 전체를 대조 완료했다는 뜻은 아니다. 현재 은행에는 버전 선택 메뉴나 확인하지 않은 문항 출제 연도·회차를 부여하지 않는다. 실기(전기설비설계 및 관리)는 이 앱의 범위 밖이다.
