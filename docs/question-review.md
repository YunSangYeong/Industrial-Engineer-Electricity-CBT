# 문제은행 작성·검수 기록

작성일: 2026-10-21. 기출 원문과 복원 자료를 사용하지 않았다. 전기기능사 문제 데이터도 복사하지 않았다. AI의 일반 전기공학 지식으로 `scripts/generate_bank.py`의 25개 원고 템플릿을 새로 작성했다. `sourceUrl`의 저장소 문서는 작성 위치와 검토 기록이며, 외부 정답 증빙·공식 인증이 아니다. 읽지 않은 교재나 문헌을 인용하지 않는다.

## 실제 수량과 의미

기본 JSON: `src/data/questions-main.json`. **자체 제작 1,000개, 원문 기출 0개, 복원 0개, 검증 대기 0개, 제외 0개, 목표 부족 0개**. 이 숫자는 **계산 원고 25개 × 입력 조건 40개**이다. 1,000개의 독립 개념이나 실제 시험 문제를 확보했다는 뜻이 아니다. 25개 원고를 기준 조건 25개와 추가 숫자 변형 975개로 구분할 수 있다. 효율·비율처럼 과목 간 공통 원리도 있어 25개의 완전히 독립적인 학문 개념이라고 주장하지 않는다.

| 과목 | 원고/계산 family | 조건 변형 포함 수 |
| --- | --- | ---: |
| 전기자기학 | 전계와 힘, 정전용량·전하, 전계 에너지, 자속, 솔레노이드 자계 | 200 |
| 전력공학 | 3상 선로 손실, 송전 효율, 부하율, 수용률, 무효전력 보상 | 200 |

전체는 계산형이며 비계산 개념형은 0개다. 각 과목의 모든 단원·실제 난이도·출제 빈도를 포괄하지 않는다. **전기설비기술기준의 200개는 설비 관련 기초 계산이고 법규·KEC 문항이 아니다.** 실제 과목을 충분히 준비하는 문제은행이라고 보기 어렵다. 최신 법규 수치와 적용일은 따로 검증해야 한다.

## 실제 검수 범위

`reviewed`는 다음 **내부 검수**를 마친 상태다. 외부 전문가 검수, 공식 문항 인증, 독립적인 사람의 전수 검수와 구별한다.

- 25개 원고의 질문·가정·정답·해설 문장을 검토했다. 전계의 단위, μF·μC·cm² 변환, 평면에 수직인 자속, 솔레노이드 단부 무시, 한 선 저항 기준 3I²R, 동일 기간의 최대/평균 전력, 전동기 운전의 슬립, RMS 교류값, 한 가닥 전선 길이, 무차원 부등률을 구분했다.
- 변압기는 손실·전압강하 없는 이상 모델이다. 토크 문제는 9550 근사상수를 본문에 명시했다. 조명 이용률·보수율과 고유저항은 법정값이 아닌 주어진 가정이다. 일정 전력의 전력량을 요금 또는 수용률과 혼동하지 않았다.
- 모든 조건은 양수이며 송전/기기 효율과 부하율·수용률은 100% 이하, 슬립은 전동기 운전 범위다. 같은 원고 안의 40개 입력 조합은 서로 다르다.
- 생성 코드와 분리된 TypeScript 식으로 1,000개 결과를 재계산하고 정답 번호·단위·동치 보기의 유일성·해설 수치 삽입을 검사한다. 정답은 1부터 시작한다. 소수점 표시는 최대 셋째 자리이며 현재 생성 조건에서는 표시 손실 없이 계산 가능하다. 반올림 규칙 때문에 다른 보기가 동치가 되지 않는지도 검사한다.
- ID와 NFKC/공백 정규화 본문·보기(보기 순서 무시)를 검사한다. 1,000개 모두 고유하다. 의미 검토에서는 숫자 변형을 `family`로 묶고, 주제가 겹치는 원고를 독립 기출처럼 세지 않았다. 같은 맥락·같은 조건을 문장만 바꿔 추가하지 않았다. 숫자만 다른 변형을 모두 제거한 뒤의 원고 수는 25개다.
- 결정적 순서와 `IEE-원고번호-조건번호` ID를 사용하며 무작위 시드는 사용하지 않는다. 재생성이 바이트 단위로 같은지 테스트한다. 추후 문항을 확대할 때 기존 ID와 풀이 기록 참조를 유지한다.

공식 시험의 **규칙**은 Q-Net에서 직접 확인했다. 그러나 세부 출제기준 문서의 항목별 문항 매핑과 외부 전문가 검수는 아직 하지 않았다. 원문 기출의 연도·회차·공식 정답·재배포 허용 조건을 확보하지 않았으므로 기출로 등록한 항목은 없다. 모든 자체 제작 문항의 `year`, `session`은 `null`이다.

## 추출·가져오기

과목마다 20개를 추출한다. 우선 각 family에서 한 문제씩 선택하고 부족한 15개를 같은 과목의 남은 고유 ID로 보충한다. 현재는 과목마다 5개 family뿐이므로 한 시험에서 숫자 변형 유형이 반복된다. 기출 난이도·주제 분포 재현을 보장하지 않는다. 랜덤 학습은 한 순회 내 ID 중복을 막지만 같은 유형의 다른 수치는 만날 수 있다.

JSON/CSV 등록은 기본적으로 검증 대기이고 로컬에서만 보관한다. ID/정규화 본문·보기 중복을 제외하고 한 행이라도 형식 오류가 있으면 등록 전체를 중단한다. 출처·이용 권한·정답·풀이를 직접 확인한 뒤 검수 근거와 확인란을 입력해야 로컬 승인할 수 있다. UI는 그 증빙의 진실성을 자동 인증하지 않는다. 개인 등록분은 위 기본 1,000개 집계에 포함하지 않는다.
